This project demonstrates comprehensive testing practices in a Spring Boot application, covering unit testing, integration testing, mocking, and test report generation. Key topics and tools explored include:

✅ Introduction to Testing – Overview of the importance of testing in Spring Boot applications.

🧪 JUnit & AssertJ – Writing clean, maintainable unit tests using the JUnit framework with fluent assertions from AssertJ.

⚖️ Unit vs Integration Testing – Understanding the difference, purpose, and appropriate usage of both testing types.

💾 Persistence Layer Testing with TestContainers – Testing repositories using real databases spun up in Docker containers.

🧸 Mocking with Mockito – Using the Mockito library to isolate dependencies and simulate behaviors for more focused tests.

🛠️ Service Layer Testing – Writing unit tests for service classes using mocked dependencies.

🔗 Integration Testing in Spring – Full-stack tests verifying the interaction between multiple layers and components.

📊 JaCoCo Test Report Generation – Measuring code coverage and generating test reports using JaCoCo.
